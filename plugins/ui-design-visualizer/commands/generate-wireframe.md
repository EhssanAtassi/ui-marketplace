I'll help you quickly generate wireframes for your UI design.

## Quick Wireframe Generation

Simply describe what you need, and I'll create ASCII wireframes showing the layout structure.

### Example Requests

**Simple:**
- "Login page with email and password"
- "Product card with image, title, price, and add to cart button"
- "Dashboard with 4 stat cards and a chart"

**Detailed:**
- "E-commerce product page with image gallery, product details, pricing, reviews, and related products section"
- "SaaS landing page with hero section, features grid, pricing table, and testimonials"
- "Mobile app home screen with bottom navigation and card-based feed"

### What I'll Provide

For each wireframe, you'll get:

1. **ASCII Wireframe** - Visual representation using text characters
   ```
   ┌─────────────────────┐
   │ [Logo]     [Menu]   │
   ├─────────────────────┤
   │                     │
   │   Main Content      │
   │                     │
   └─────────────────────┘
   ```

2. **Layout Description** - Explanation of sections and components
3. **Responsive Variants** - Desktop, tablet, and mobile versions
4. **Component Breakdown** - List of UI components needed
5. **Interaction Notes** - Key user interactions and flows

### Supported Page Types

- **Landing Pages**: Marketing, SaaS, app downloads
- **Authentication**: Login, signup, forgot password, verify email
- **E-commerce**: Product listing, detail, cart, checkout
- **Dashboards**: Analytics, admin panels, project management
- **Content**: Blog homepage, article pages, profiles
- **Applications**: Email clients, chat apps, calendars
- **Mobile Screens**: Feeds, profiles, settings, navigation

### Customization Options

Specify any of these to customize your wireframe:
- Platform: Web, mobile app, desktop app, tablet
- Orientation: Portrait, landscape
- Complexity: Simple, standard, complex
- Sections to include: Header, sidebar, footer, etc.
- Special requirements: Multi-step, tabbed, modal-based
