## What is a Component Library?

A component library is a collection of reusable UI components with:
- Multiple variants (primary, secondary, sizes)
- Different states (default, hover, active, disabled)
- Comprehensive documentation
- Production-ready code
- Accessibility features

## What You'll Get

For each component in your library, I'll provide:

1. **Complete HTML Structure**
   ```html
   <!-- button.component.html -->
   <button type="button" class="btn btn-primary">
     Click Me
   </button>
   ```

2. **Full CSS with Variants**
   ```css
   /* All states and variants */
   .btn-primary { }
   .btn-secondary { }
   .btn-sm { }
   .btn-lg { }
   .btn:hover { }
   .btn:disabled { }
   ```

3. **TypeScript Component Logic** (for Angular/React)
   ```typescript
   /* With Swagger documentation */
   @Component({ ... })
   export class ButtonComponent { }
   ```

4. **Usage Examples**
   - How to use each variant
   - Common patterns
   - Do's and don'ts

5. **Accessibility Documentation**
   - ARIA attributes
   - Keyboard navigation
   - Screen reader support
   - WCAG 2.1 AA compliance

6. **Design Tokens Integration**
   - Uses CSS custom properties
   - Themeable variables
   - Consistent spacing/colors

## Customization Options

Specify any of these:
- **Framework**: Angular, React, Vue, or framework-agnostic
- **Styling**: Tailwind, CSS Modules, Styled Components, plain CSS
- **Design System**: Material, Ant Design, custom
- **Color Scheme**: Brand colors or default
- **Variants**: Number and types of variants needed
- **States**: Which interaction states to include
- **Accessibility Level**: WCAG 2.0 AA, WCAG 2.1 AA, WCAG 2.1 AAA
